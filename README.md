Zapret_app_Pff — независимый графический интерфейс для Windows-сборки Flowseal. Он загружает стратегии Flowseal, проверяет доступность Discord и YouTube и показывает, какая стратегия лучше работает в текущей сети. [Исходный проект Flowseal](https://github.com/Flowseal/zapret-discord-youtube)

## Быстрый старт

1. Скачайте **Zapret_app_Pff.exe** из последнего релиза. Поддерживаются Windows 10 22H2 и Windows 11 x64.
2. Запустите установщик и подтвердите запрос администратора. При первом запуске приложению понадобится GitHub, чтобы скачать актуальный пакет Flowseal. Среда выполнения .NET 10 уже входит в установщик.
3. Дождитесь первого теста, затем нажмите **Включить**. Стрелка рядом со стратегией запускает её вручную. Крестик сворачивает окно в трей, а **Выход** в меню трея останавливает приложение и запущенный им `winws`.

Один файл установщика можно переслать другому пользователю Windows. Установщик поставляется без цифровой подписи. [Последний релиз](https://github.com/SandrikPff/Zapret_app_Pff/releases/latest)

## Что добавляет Zapret_app_Pff

| Задача | Стандартная сборка Flowseal | Zapret_app_Pff |
| --- | --- | --- |
| Запуск и остановка | Отдельные BAT-файлы и меню службы | Список стратегий в одном окне, управление кнопкой или из трея |
| Подбор стратегии | Тесты запускаются отдельным сценарием | Рейтинг по доступным портам и задержке, быстрый тест лидеров и полный тест |
| Обновление | Выпуски и архивы на GitHub, проверка версии через меню | Проверка при запуске, уведомление о новом релизе, установка автоматически или по кнопке |
| Запуск вместе с Windows | Установка выбранной стратегии как службы | Запуск в трее и автоподключение по результатам последней проверки |
| Параметры | Меню `service.bat` и пользовательские списки | Игровой фильтр, IPSet, управление `hosts` и диагностика в настройках |

Сравнение относится к Windows-пакету Flowseal и его комплектным сценариям. [Репозиторий Flowseal](https://github.com/Flowseal/zapret-discord-youtube)

## Что есть в приложении

- **Стратегии.** Число доступных адресов и портов, медианная задержка, ручное переключение и подсказки с результатом каждого запроса.
- **Быстрый и полный тесты.** Быстрый тест перепроверяет до четырёх лидеров. При ухудшении результата проверяются оставшиеся стратегии. Полный тест запускает все стратегии релиза.
- **Обновления Flowseal.** Уведомление предлагает установить новую версию или отложить установку. В настройках отдельно включается автоматическая установка при запуске.
- **Автозапуск.** Запуск в трее при входе в Windows и автоподключение к лучшей стратегии.
- **Фильтры.** Игровые TCP- и UDP-диапазоны, режимы IPSet, пользовательские домены и исключения, выбор UDP-фейков Discord и игр.
- **Инструменты.** Обновление IPSet, добавление и удаление отдельного блока Flowseal в `hosts`, проверка BFE, WinDivert и конфликтующих процессов.
- **Оформление.** Графитовая и кремовая темы, тумблер темы, круговая палитра акцента и ползунок яркости.

### Установка релиза

При запуске приложение запрашивает сведения о последнем стабильном релизе через GitHub API. Загрузчик выбирает Windows ZIP из репозитория Flowseal, сверяет размер и SHA‑256 и распаковывает архив во временную папку. Версия становится текущей после проверки содержимого и подготовки файлов. Если обновление завершилось ошибкой, остаётся доступна предыдущая установленная версия.

Тумблер **Устанавливать обновления Flowseal при запуске** управляет скачиванием и установкой. При выключенном тумблере проверка релиза сохраняется, а уведомление предлагает **Обновить** или **Позже**. Установщик самого Zapret_app_Pff публикуется в релизах этого репозитория. [Официальные релизы Flowseal](https://github.com/Flowseal/zapret-discord-youtube/releases)

### Как считается рейтинг

Приложение читает параметры комплектных стратегий Flowseal и передаёт их напрямую в `winws.exe`. Стратегии проверяются по очереди, а девять коротких HTTP(S)-запросов для каждой стратегии идут параллельно с тайм-аутом 2,35 секунды.

1. Сначала сравнивается число ответивших пар «хост и TCP-порт».
2. При равном числе ответов выше стоит стратегия с меньшей медианной задержкой до заголовков HTTP.
3. Результаты прошлого теста остаются в списке с соответствующей пометкой. При смене сети, пакета или фильтров приложение пересчитывает рейтинг.

Эти измерения описывают HTTP(S)-доступность Discord и YouTube. Игровые UDP-порты, голосовые соединения Discord и ICMP требуют отдельных измерений. Во время теста стратегии переключаются, поэтому текущие соединения могут ненадолго прерваться.

### Что хранится в Windows

Приложение устанавливается в `%ProgramFiles%\Zapret_app_Pff`. В этой папке хранятся релизы Flowseal, а в `data\<SID пользователя>` — настройки, результаты тестов, журнал и резервная копия `hosts`. Автозапуск регистрируется в Планировщике заданий для текущей учётной записи.

## Сборка из исходников

Для сборки нужны **.NET 10 SDK** и **Git**. Если SDK ещё не установлен, установите его через PowerShell.

```powershell
winget install -e --id Microsoft.DotNet.SDK.10
```

Откройте новое окно PowerShell в папке, куда хотите скачать исходники, и выполните команды.

```powershell
git clone https://github.com/SandrikPff/Zapret_app_Pff.git
Set-Location -LiteralPath '.\Zapret_app_Pff'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Build.ps1'
```

Установщик появится в `dist\Zapret_app_Pff.exe`. Скрипт собирает Windows x64 приложение, включает рантайм и деинсталлятор, затем печатает SHA‑256 готового файла.

### Проверки

```powershell
dotnet run --project .\tests\ZapretAppPff.Checks
dotnet run --project .\tests\ZapretAppPff.Checks -- --upstream
```

Проверки охватывают загрузку и распаковку релиза, разбор параметров стратегий, рейтинг, фильтры и XML задачи автозапуска. Интеграцию WinDivert, трея и Планировщика проверяют на Windows x64.

## Удаление

Откройте **Параметры → Приложения → Установленные приложения → Zapret_app_Pff → Удалить**. Деинсталлятор закрывает приложение, удаляет его задачи автозапуска, добавленный им блок `hosts` и файлы установки.
